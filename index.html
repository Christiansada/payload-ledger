02 / COMPARISON RULES

Make the comparison intentional.

Objects compare by key. Arrays compare by position unless record matching is enabled.

Use an empty pointer for a root array. IDs must be unique strings or numbers. Reordering is informational.

Exact paths exclude their subtree. Use ~1 for / and ~0 for ~ in keys. Exclusions cannot overlap an ID-matched array.
