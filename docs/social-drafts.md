## LinkedIn

I built Payload Ledger, a small JSON fixture review tool for API developers and testers.

It compares parsed fields, matches records in one array by a unique ID, and lets you exclude explicit volatile paths. The ledger distinguishes additions, removals, type changes and value changes, with both source locations preserved when records move.

The interface runs locally in the browser and exports a JSON review. It includes synthetic examples, input validation, automated tests and accessibility checks. It is a review aid—not an API compatibility verdict—and uses JavaScript number precision.

Try the [live app](https://christiansada.github.io/payload-ledger/) and explore the [MIT-licensed source](https://github.com/Christiansada/payload-ledger). Useful next contributions include independent nested-data test oracles, screen-reader testing and exact decimal handling.
